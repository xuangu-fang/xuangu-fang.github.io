# Roadmap Templates

这个文件夹包含了创建新roadmap的模板文件。

## 使用方法

1. 复制 `template.md` 文件到 `_roadmap/` 文件夹
2. 重命名为你想要的名称，例如：`my-research-roadmap.md`
3. 编辑文件内容，替换模板中的占位符
4. 添加相应的图片到 `images/roadmap/` 文件夹
5. 更新图片路径引用

## 模板结构

模板包含以下部分：
- **Front matter**: 标题、摘要、collection设置
- **Overview**: 研究方向的概述
- **Key Research Areas**: 主要研究领域
- **Research Roadmap**: 研究时间线
- **Technical Approach**: 技术方法
- **Expected Outcomes**: 预期成果
- **Related Work**: 相关工作

## 注意事项

- 确保图片路径正确
- 保持markdown格式的一致性
- 定期更新roadmap内容
